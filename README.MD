# DownShift

**A gravity-bending puzzle platformer. My first JavaScript game.**

🎮 **[Play DownShift](https://nxtcreator.github.io/downshift/)** — best played on desktop with a keyboard.

You're a tiny maintenance robot trapped in an abandoned research facility. The gravity core has failed, and the only way forward is to flip gravity between the floor and ceiling. Solve puzzles, fix the relays, and make your way to the core.

## Controls

| Key | Action |
|---|---|
| Left / Right | Move |
| Up | Jump |
| Space | Flip gravity |
| R | Restart the level |

Gravity flips are limited, so think before you leap!

## What's in the game?

- 5 levels, each introducing a different challenge.
- Gravity-flipping puzzles that make you rethink how you move.
- Slime, crates, buttons, and doors.
- A final level that brings everything together.

## My first game (and the struggle behind it)

This is my first game, my first time using a game engine, and one of my biggest JavaScript projects so far.

And honestly? **It was a pain.**

Things broke in ways I didn't understand. The robot fell in slow motion. Crates had a mind of their own. Parts of levels disappeared because they didn't fit on the screen. Sometimes I'd spend ages debugging something only to discover I'd made a tiny mistake.

There were moments when I wasn't sure what was wrong or how to fix it. But every bug I worked through taught me something new, and slowly, things started coming together.

The game isn't perfect, but that's kind of the point. I wanted to finish something real, learn along the way, and prove to myself that I could build a game from scratch.

I'm proud of getting it this far, and I'm excited to keep learning.
